The temporal branch does not score the clip as a whole: it scores overlapping 16-frame windows and takes the maximum. Each bar is one scored window — click one to select it for saliency. In REPLAY mode these probabilities are replayed from the committed scores; in LIVE MODEL mode each one was produced by an R3D-18 forward pass during that run. Spatial evidence

Observed detections and measurements, kept separate from the model probability and from the configured severity. An undefined value stays Unavailable — it is never shown as zero.

Evidence fusion

A configured fusion layer combining the temporal probability with an interpretable spatial motion feature. The spatial feature is a whole-video aggregate, so the fusion decision is available only after the whole video has been processed — it is not a causal mid-video alarm. Thresholds are read from the frozen protocol, not tuned here.

In the frozen confirmatory evaluation, fusion did not produce a statistically significant improvement over the temporal-only baseline (exact McNemar p = 0.771). The temporal-only rule remains the system's decision. Fusion is shown because the research question concerns an explainable multi-signal system, not because it performs better.

Gradient-based temporal saliency

Saliency is computed on demand for one completed 16-frame window, not for every frame: it needs a backward pass as well as a forward one (about 2.2 s per window on this CPU, measured). It is unavailable in the default replay path, which has a recorded probability but no model weights to differentiate.
